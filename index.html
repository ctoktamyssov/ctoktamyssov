8-Bit Breadboard Computer

A fully programmable 8-bit computer. It contains a clock module, registers, ALU, RAM, and a CPU. The CPU is an EEPROM which decodes an assembly-type instruction set:
LDA = load register A,
ADD = add number in memory XXXX to A,
HLT = stop the clock,
and many more. The most complex program that I have programmed and ran on the machine is a Fibonacci sequence generator which is demonstrated in the attached video.

Computer Architecture 74HC Logic Assembly

Rubik's Cube Solver

A Rubik's cube solving robot. The UI is built with React serving as the frontend and Node.js + Express as the backend. After inputting a scrambled cube, a solution is computed using cubejs, then sent over via UART to an ESP32. The microcontroller controls six NEMA stepper motors which manipulate the cube.

React Node.js ESP32 Steppers

Digital Clock

A digital clock running on an Arduino Nano. The lights are formed in four separate 7-segment displays controlled by shift registers on a custom PCB I designed using KiCad. The frame is built from plywood and 3D printed parts, and the art is inspired by Arcane and was drawn by a friend.

Three Body Problem

Simulates the three body problem in real time with C++ and OpenGL, using RK4 integration for accurate physics and GLM for vector math. A visualization of the orbital system from Cixin Liu's book series.
