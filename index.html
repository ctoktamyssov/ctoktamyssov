8-Bit Breadboard Computer

A fully programmable 8-bit computer built from 74HC-series logic chips — a clock module, registers, ALU, RAM, program counter, and output register sharing one data bus. A 28C16 EEPROM control unit decodes a custom instruction set (LDA, ADD, SUB, JMP, OUT, HLT), and it runs assembly like a Fibonacci generator on real hardware.

74HC Logic EEPROM Assembly

Rubik's Cube Solver

A full-stack cube solving robot: a React frontend and a Node.js + Express backend compute the solution with cubejs, then send it over USB serial to an ESP32 that drives the stepper motors turning the cube.
